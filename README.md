# Dataset

The file `transactions_supermarche.csv` contains supermarket transaction records.

Columns:
- `Transaction_ID`: transaction identifier.
- `Produit`: product recorded in the transaction.

The dataset contains 500 transactions, 20 unique products, and 1,968 records.

Keep this file in the `data/` directory when running the notebook from the repository root.

Before publishing this dataset publicly, make sure you have permission to redistribute it.
